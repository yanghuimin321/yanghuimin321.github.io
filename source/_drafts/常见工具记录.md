# 概念

#### 1. SEO(Search Engine Optimization) ：搜索引擎优化

- 通过了解搜索引擎的运行规则，对网站进行内部和外部的调整优化，**提高网站在搜索引擎中的自然(非付费)搜索结果中的排名**，从而获得更多免费流量和曝光的一系列技术和策略

#### 2. BFC(Block fomatting context)：块级格式化上下文

- Web页面中一个**独立的渲染区域**，区域内部的规则与外部隔离，内部元素不会影响到外部元素
- 核心作用：
  - 包含内部浮动（解决高度塌陷）
  - 隔离外部浮动（阻止元素被浮动元素覆盖）
  - 阻止外边距margin重叠
- IFC(inline formatting context)、G(grid)FC、F(flex)FC

#### 4. SFC(Single-File Components)：单文件组件

#### 3. **渐进式框架**： 一种允许开发者根据项目需求**逐步采用**其功能的框架设计理念。

- 核心思想：可以从轻量级使用开始，逐步扩展为功能完整的方案
- 分层架构：
  - **核心库**： 只关注视图层，处理基本视图渲染/响应式数据绑定
  - **附加层**： 路由、全局状态管理、构建工具等



# 工具/技术栈

#### 1. Babel：一个JS编译器，从源代码到源代码

- 将采用ES6+语法编写的代码，转换为向后兼容的JS语法，以便能运行在当前和旧版本的浏览器或其他环境中

#### 2. Polyfill：**运行时的兼容方案**，让旧浏览器能执行新 API

- 一段代码，用于在不支持某些新特性的旧浏览器中模拟实现这些特性，使开发者能够使用最新的 API 编写代码，同时保持向后兼容

- 常见Polyfill类型：JavaScript API，CSS 特性，Web API

#### 3.PostCSS：**构建时的转换工具**，让 CSS 代码更现代化且兼容旧浏览器

- CSS 处理工具。它本身不操作 CSS，而是通过插件系统来转换 CSS
